# SUBMISSION_1 15-Family OOD Protocol

`SUBMISSION_1` uses a fixed 15-family protocol:

| Split | Families | Purpose |
| --- | --- | --- |
| Train | `mosfet`, `igbt`, `ic`, `scfam01`..`scfam09` | 12-family model training |
| Held-out OOD | `scfam10`, `scfam11`, `scfam12` | Family-wise OOD average |

The synthetic families are generated by `generate_submission_1_families.py`.
They use existing process-step vocabulary only and are validated with
`training_data.generate_sequences.validate_sequence`.

## Commands

```bash
python generate_submission_1_families.py --count-per-family 200
python train.py --model gpt:large --submission-1-ood --epochs 30 --out outputs/gpt_large_train12
python eval_guided.py --kind gpt --size large --submission-1-ood --checkpoint outputs/gpt_large_train12 --eval-seqs 500
```
