Team Kremsians built an Industrial AI system for semiconductor process logic.
The input is a partial fab sequence. The output is three official files:
nextstep dot csv, completion dot csv, and anomaly dot csv.

We start locally on an Apple Silicon MacBook. The same repository generates the
fifteen-family benchmark, trains a from-scratch step-token GPT, and detects MPS
automatically. This is not a generic LLM wrapper. One process step is one token,
so the model is trained on exactly the unit the scorer evaluates.

The same code path also runs on Leonardo. On the cluster, CUDA is detected, the
SLURM job starts the A100 run, regenerates the official-format CSVs, and scores
the local self-eval split with the organizer metrics.

Our evaluation is intentionally out-of-distribution. We use fifteen families:
the three organizer families plus twelve synthetic process families. The final
protocol trains on twelve and tests on three held-out families, then reports the
family-wise average. No official eval sequence is used as training data.

On the held-out families, GPT improves next-step Top-1 from zero point six six
two to zero point seven two two, and Top-5 from zero point nine seven six to
zero point nine nine nine. On the official-scorer self-eval split, completion
normalized edit distance drops from zero point three three six to zero point two
six three. For anomaly detection, the process rules are explicit, so our
deterministic validator gives F1, ROC-AUC, and rule attribution of one point
zero zero.

The final repository contains the checkpoint, loss curve, score reports,
official-format CSVs, pitch deck, and this demo video. It is reproducible on
both Apple M4 Pro and Leonardo, with the exact commands documented at the root.
