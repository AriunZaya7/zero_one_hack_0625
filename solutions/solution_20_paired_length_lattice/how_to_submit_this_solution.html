3. Check The Three Required CSVs

The files to submit are exactly these:

solutions/solution_20_paired_length_lattice/outputs/official_submission/nextstep.csv
solutions/solution_20_paired_length_lattice/outputs/official_submission/completion.csv
solutions/solution_20_paired_length_lattice/outputs/official_submission/anomaly.csv

They must have these exact headers:

nextstep.csv: EXAMPLE_ID,RANK_1,RANK_2,RANK_3,RANK_4,RANK_5
completion.csv: EXAMPLE_ID,PREDICTED_SEQUENCE
anomaly.csv: EXAMPLE_ID,IS_VALID,SCORE,PREDICTED_RULE

Run this quick local header and row-count check:

python - <<'PY'
import csv
from pathlib import Path

base = Path("solutions/solution_20_paired_length_lattice/outputs/official_submission")
expected = {
    "nextstep.csv": (["EXAMPLE_ID", "RANK_1", "RANK_2", "RANK_3", "RANK_4", "RANK_5"], 600),
    "completion.csv": (["EXAMPLE_ID", "PREDICTED_SEQUENCE"], 600),
    "anomaly.csv": (["EXAMPLE_ID", "IS_VALID", "SCORE", "PREDICTED_RULE"], 987),
}
for name, (header, rows) in expected.items():
    with (base / name).open(newline="", encoding="utf-8") as f:
        reader = csv.reader(f)
        actual_header = next(reader)
        actual_rows = sum(1 for _ in reader)
    print(name, actual_header == header, actual_rows == rows, actual_rows)
PY

4. Regenerate The Package

If the jury wants a full folder package, run:

python -B solutions/prepare_submission_packages.py

Then use the generated folder: 

solutions/solution_20_paired_length_lattice/submission_package/

5. What To Click In The Submission UI

  1. Open the hackathon submission page or Tally form in the browser.
  2. Choose the Industrial AI track.
  3. Upload nextstep.csv when the form asks for next-step predictions.
  4. Upload completion.csv when the form asks for sequence completion predictions.
  5. Upload anomaly.csv when the form asks for anomaly predictions.
  6. If the form asks for a report, use submission_package/REPORT.md.
  7. If the form asks for supporting artifacts, upload or link the full submission_package/ folder.
  8. Before final submit, visually confirm the file names shown by the form match the three CSVs above.
