Solution 5: Tuned Rank Ensemble

What This Solution Tries

Solution 5 changes only Task 1 scoring. Instead of using one trigram fallback, it combines retrieval votes with n-gram models of order 3, 4, and 5.

An n-gram model predicts the next step from recent step history. Order 3 means "look at the previous two steps"; order 5 means "look at the previous four steps". Combining several orders can make the ranker less brittle when one context length is too specific or too vague.

Key Code Idea

for model in self.ngrams.values():
    for rank, step in enumerate(model.next_step_ranking(prefix, k=20)):
        scores[step] += NGRAM_WEIGHT / (rank + 1) / len(self.ngrams)

Retrieval still supplies the main route candidates. The n-gram ensemble adjusts their ranking.
