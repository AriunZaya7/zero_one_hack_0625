How To Submit Solution 19

This page gives manual steps for preparing the Solution 19 CSV files and package from the shared repository checkout.

1. Confirm Branch

cd /Users/batikanorpava/Documents/other_development/2026-may30-vienna/zero_one_hack_0625
git branch --show-current

The branch should be dev/bati.

2. Regenerate Solution Outputs

python -B solutions/solution_19_valid_lattice_template/solution.py

This rewrites the official-shaped CSVs and the extra audit files under solutions/solution_19_valid_lattice_template/outputs/.

3. Check The Required CSV Files

The three files to submit for the Industrial AI CSV part are:

  • solutions/solution_19_valid_lattice_template/outputs/official_submission/nextstep.csv
  • solutions/solution_19_valid_lattice_template/outputs/official_submission/completion.csv
  • solutions/solution_19_valid_lattice_template/outputs/official_submission/anomaly.csv

They must keep exactly these headers:

  • EXAMPLE_ID,RANK_1,RANK_2,RANK_3,RANK_4,RANK_5
  • EXAMPLE_ID,PREDICTED_SEQUENCE
  • EXAMPLE_ID,IS_VALID,SCORE,PREDICTED_RULE

4. Regenerate Submission Package

python -B solutions/prepare_submission_packages.py

This copies the official CSV files, metrics, report, training notes, and demo notes into solutions/solution_19_valid_lattice_template/submission_package/.

5. Inspect Extra Evidence

These files are not official CSV submissions, but they are useful for the report and demo:

  • outputs/lattice_guard_audit.csv: says whether each row used full-route memory, valid-lattice evidence, or template fallback.
  • outputs/lattice_training_manifest.csv: counts training routes and lattice coverage.
  • outputs/metrics.md: human-readable metric summary.

Submission Warning

Only upload files requested by the organizers. The audit and manifest files are supporting evidence, not replacements for the three required CSVs.
