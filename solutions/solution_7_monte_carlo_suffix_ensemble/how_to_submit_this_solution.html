How To Submit Solution 7

This page explains the manual steps for submitting solution_7_monte_carlo_suffix_ensemble. It assumes you are a team member working from the repository root.

What This Folder Contains

File or folder Purpose
solution.py Runs the Solution 7 model and writes the three output CSVs.
outputs/nextstep.csv Task 1 local next-step predictions in the required column shape.
outputs/completion.csv Task 2 local suffix completion predictions in the required column shape.
outputs/anomaly.csv Task 3 local anomaly predictions in the required column shape.
outputs/metrics.json and outputs/metrics.md Local self-evaluation results. These are not official hidden-eval scores.
submission_package/ Generated package folder with report, mirrored CSVs, metrics, and demo notes.

Step 1: Confirm The Branch

We are only working on dev/bati. Before doing anything else, open a terminal and run:

git branch --show-current

The output should be: 

dev/bati

If it is not dev/bati, switch before regenerating anything:

Step 2: Regenerate The Local Outputs

Run the Solution 7 script: 

python -B solutions/solution_7_monte_carlo_suffix_ensemble/solution.py

This script takes longer than the smallest baselines because it generates 10,000 valid completion-library sequences per known family. That is expected. At the end, it prints a JSON metrics block and writes: 

solutions/solution_7_monte_carlo_suffix_ensemble/outputs/nextstep.csv
solutions/solution_7_monte_carlo_suffix_ensemble/outputs/completion.csv
solutions/solution_7_monte_carlo_suffix_ensemble/outputs/anomaly.csv
solutions/solution_7_monte_carlo_suffix_ensemble/outputs/metrics.json
solutions/solution_7_monte_carlo_suffix_ensemble/outputs/metrics.md

nextstep.csv and completion.csv should each have 600 prediction rows plus a header row. anomaly.csv should have 987 prediction rows plus a header row. You can check this quickly: 

wc -l solutions/solution_7_monte_carlo_suffix_ensemble/outputs/nextstep.csv
wc -l solutions/solution_7_monte_carlo_suffix_ensemble/outputs/completion.csv
wc -l solutions/solution_7_monte_carlo_suffix_ensemble/outputs/anomaly.csv

Step 5: Understand What To Upload

The CSVs currently generated by this folder are local self-eval outputs, not official hidden-eval outputs. The official organizer eval input files and hidden ground truth are not present in this checkout.

If the organizers give files named like eval_input_valid.csv and eval_input_anomaly.csv, the submission script should be adapted to read those official input rows and emit the same three CSV formats. The output columns must remain the same.

The manual upload mapping should be:

Organizer task Upload from Solution 7 package
Task 1 next-step prediction submission_package/extras/results/nextstep.csv
Task 2 completion submission_package/extras/results/completion.csv
Task 3 anomaly detection submission_package/extras/results/anomaly.csv
Technical report submission_package/REPORT.md, converted to PDF if the platform requires PDF.
Slides and demo video Use extras/demo/pitch_slides_outline.md and extras/demo/video_script.md as the source material for the final uploaded media.

Step 6: Suggested Pitch Notes

When explaining this solution to judges, say it directly:

  • "We found that next-step ranking and full completion reward different behavior, so Solution 7 uses task-specialized specialists."
  • "For next-step ranking, we preserve the stronger leave-one-family-out retrieval model."
  • "For completion, we generate a larger valid route library from the public process grammar and retrieve the most compatible remaining suffix."
  • "This improved local completion normalized edit distance to 0.2333, token accuracy to 0.4737, and block accuracy to 0.7367."
  • "The exact full-suffix metric remains harsh because valid optional steps and aliases create many plausible futures."
