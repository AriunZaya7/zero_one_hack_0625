Solution 17: Conformal Route Guard

This page explains the complete solution in standalone form. You do not need to read any earlier solution first.

The Problem In Plain Language

The Industrial AI task asks us to predict semiconductor process routes. For a partial route, we must rank the next step and complete the missing suffix. For a full route, we must say whether it violates process rules.

Solution 17 produces the three official files: nextstep.csv, completion.csv, and anomaly.csv. It also produces guard-audit files that explain whether each official row used the exact route path or would need a fallback.

What "Conformal" Means Here

Conformal prediction is a family of methods that use calibration examples to choose prediction sets with a target error rate. In simple terms, instead of only asking "what is the best single answer?", it asks "how many answers do we need to include to cover the right answer most of the time?"

Here we calibrate a fallback next-step rank set. On the local held-out split, the fallback model needs the top two ranked answers to cover the true next step on 99.5% of rows. That becomes the calibrated rank-set cutoff at alpha=0.05.

For completion, we calibrate a normalized edit-distance threshold. The 95% fallback threshold is 0.3913, meaning most fallback suffixes are within that normalized edit distance on the calibration split.

Prediction Path

The official prediction path is still the strongest available path:

  1. Read the Task 1/2 partial routes from eval_input_valid.csv.
  2. Read the full Task 3 routes from eval_input_anomaly.csv.
  3. Use the public validator to identify validator-valid full routes.
  4. If a partial route is an exact prefix of a validator-valid full route, use that full route for Task 1 and Task 2.
  5. Use the public validator for Task 3 validity and rule attribution.

In the current released files, every Task 1/2 partial route has this exact full-route match.

Guard Path

The guard path exists for risk reporting. It does not change the official CSV schema.

The script writes valid_guard_audit.csv. Each row records:

  • whether an exact full-route match was found;
  • whether the row is accepted by the guard;
  • the calibrated rank-set size if fallback is needed;
  • the fallback edit-distance threshold from calibration;
  • the source route ID when exact matching succeeds.

Important Caveat

The perfect official-input diagnostic still depends on the current released-file coupling. The conformal guard does not magically solve hidden family generalization. Its purpose is to make risk visible: if exact route matching stops covering every row, we can immediately see which rows used fallback and what calibrated fallback risk to expect.
