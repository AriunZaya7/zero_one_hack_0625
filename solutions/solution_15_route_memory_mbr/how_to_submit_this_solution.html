How To Submit Solution 15: Route Memory MBR

Use these manual steps from the repository root on branch dev/bati.

1. Check The Branch

git branch --show-current
git status --short --branch

The branch should be dev/bati. The status should not show unrelated local changes before you regenerate outputs.

2. Regenerate The Solution Outputs

python -B solutions/solution_15_route_memory_mbr/solution.py

This writes the source outputs and the official-input submission copy:

  • solutions/solution_15_route_memory_mbr/outputs/official_submission/nextstep.csv
  • solutions/solution_15_route_memory_mbr/outputs/official_submission/completion.csv
  • solutions/solution_15_route_memory_mbr/outputs/official_submission/anomaly.csv

3. Regenerate All Submission Packages

python -B solutions/generate_official_submissions.py
python -B solutions/prepare_submission_packages.py

The package generator copies the official-input CSVs into:

  • solutions/solution_15_route_memory_mbr/submission_package/extras/results/nextstep.csv
  • solutions/solution_15_route_memory_mbr/submission_package/extras/results/completion.csv
  • solutions/solution_15_route_memory_mbr/submission_package/extras/results/anomaly.csv

4. Check CSV Shape

python - <<'PY'
import csv
from pathlib import Path
root = Path("solutions/solution_15_route_memory_mbr/submission_package/extras/results")
expected = {
    "nextstep.csv": (["EXAMPLE_ID","RANK_1","RANK_2","RANK_3","RANK_4","RANK_5"], 600),
    "completion.csv": (["EXAMPLE_ID","PREDICTED_SEQUENCE"], 600),
    "anomaly.csv": (["EXAMPLE_ID","IS_VALID","SCORE","PREDICTED_RULE"], 987),
}
for name, (header, rows) in expected.items():
    with (root / name).open(newline="", encoding="utf-8") as f:
        reader = csv.reader(f)
        actual_header = next(reader)
        actual_rows = sum(1 for _ in reader)
    assert actual_header == header, (name, actual_header)
    assert actual_rows == rows, (name, actual_rows)
print("Solution 15 CSVs are submission-shaped.")
PY
