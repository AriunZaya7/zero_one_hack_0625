How to Submit Solution 13

This page gives manual submission steps for the transductive generator-validator solution. It assumes you are in the repository root on branch dev/bati.

1. Confirm the official input files are present

ls tracks/industrial-infineon/participant_files

You should see:

  • eval_input_valid.csv
  • eval_input_anomaly.csv
  • eval_metrics.py

2. Regenerate this solution

python -B solutions/solution_13_transductive_generator_validator/solution.py

The command writes the three official-shaped CSV files into solutions/solution_13_transductive_generator_validator/outputs/ and mirrors them into outputs/official_submission/.

3. Check the files that matter for submission

python -B - <<'PY'
from pathlib import Path
import csv

root = Path("solutions/solution_13_transductive_generator_validator/outputs/official_submission")
expected = {
    "nextstep.csv": (["EXAMPLE_ID", "RANK_1", "RANK_2", "RANK_3", "RANK_4", "RANK_5"], 600),
    "completion.csv": (["EXAMPLE_ID", "PREDICTED_SEQUENCE"], 600),
    "anomaly.csv": (["EXAMPLE_ID", "IS_VALID", "SCORE", "PREDICTED_RULE"], 987),
}
for name, (header, rows_expected) in expected.items():
    with (root / name).open(newline="", encoding="utf-8") as f:
        reader = csv.reader(f)
        actual_header = next(reader)
        rows = sum(1 for _ in reader)
    print(name, actual_header == header, rows)
    assert actual_header == header
    assert rows == rows_expected
PY

4. Refresh the package folder

python -B solutions/prepare_submission_packages.py

This copies the official submission CSVs into:

  • solutions/solution_13_transductive_generator_validator/submission_package/extras/results/nextstep.csv
  • solutions/solution_13_transductive_generator_validator/submission_package/extras/results/completion.csv
  • solutions/solution_13_transductive_generator_validator/submission_package/extras/results/anomaly.csv

5. Upload or attach the CSVs

When the hackathon submission form asks for the Industrial AI CSV files, use the three files under the solution package's extras/results/ folder. Do not rename columns and do not change delimiters.

6. Explain the method honestly

Say that this is a transductive participant-input strategy. It uses validator-valid full sequences from the anomaly input as full-route candidates for exact prefix completion. That is why it is an upper-bound candidate for the released files.

7. Commit and push after changes

git status --short --branch
git add solutions/solution_13_transductive_generator_validator solutions/solutions_comparison.md solutions/submission_readiness_audit.md
git commit -m "Add transductive generator validator solution"
git push origin dev/bati
