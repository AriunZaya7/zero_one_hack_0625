Solution 8: Semantic Conformance Ensemble

This page explains Solution 8 from scratch. The solution keeps the next-step and completion strategy from Solution 7, then replaces the direct validator call for anomaly prediction with an explicit semantic conformance checker.

What The Industrial Task Needs

The Industrial AI track asks us to reason about semiconductor process routes. A route is a long ordered list of manufacturing operations. Some operations must happen before others. For example, a lot should not be shipped before wafer sort testing, and a patterned etch should not happen before photoresist has been developed.

Task 3 asks whether a complete route is valid or anomalous. If it is anomalous, we also need to say which rule was violated.

Why Solution 8 Exists

Previous solution attempts used the public validator oracle for Task 3. That produced perfect local anomaly metrics, but it is not a satisfying explanation of model behavior. It effectively says: "ask the validator."

Solution 8 is different. It implements a separate conformance checker that looks for the same kinds of process-order problems using explicit semantic features. It does not call validate_sequence() during prediction.

For a junior engineer: conformance checking means comparing a real or proposed sequence against what a valid process is expected to look like. If the sequence breaks the expected order, the checker reports a violation.

The Semantic Checker

The checker scans a sequence and creates a list of SemanticViolation objects. Each violation records:

  • the predicted rule id, such as RULE_ETCH_NO_MASK,
  • the step index where the violation appears,
  • the step name,
  • a score penalty used to make valid sequences score higher than invalid ones,
  • a human explanation.
@dataclass(frozen=True)
class SemanticViolation:
    rule: str
    step_index: int
    step_name: str
    score_penalty: float
    explanation: str

The checker returns the first violation in sequence order. If it finds no violations, the route is predicted valid.

Examples Of Rules

Developed resist before patterned etch

A patterned etch needs a mask. In these traces, the mask is represented by a recent DEVELOP PHOTORESIST or DEVELOP PAD WINDOW step. The checker looks back 12 steps before an etch: 

for i, step in enumerate(sequence):
    if step in base.ETCH_STEPS:
        w = window(sequence, i, 12)
        if "DEVELOP PHOTORESIST" not in w and "DEVELOP PAD WINDOW" not in w:
            violations.append(SemanticViolation("RULE_ETCH_NO_MASK", ...))

CMP after deposition or fill

CMP means chemical-mechanical planarization. In plain words, it polishes material flat. It only makes sense after a recent deposition or fill step has put material there. The checker looks back 6 steps before CMP: 

for i, step in enumerate(sequence):
    if step in base.CMP_STEPS:
        if not any_in_window(sequence, i, 6, base.FILL_STEPS):
            violations.append(SemanticViolation("RULE_CMP_NO_DEP", ...))

Ship after wafer sort

This is the terminal-order sanity check. If SHIP LOT appears before WAFER SORT TEST, the lot is being shipped before final wafer sort. 

ship_idx = next((i for i, step in enumerate(sequence) if step == "SHIP LOT"), None)
sort_idx = next((i for i, step in enumerate(sequence) if step == "WAFER SORT TEST"), None)
if ship_idx is not None and (sort_idx is None or ship_idx < sort_idx):
    violations.append(SemanticViolation("RULE_SHIP_BEFORE_TEST", ...))

What This Solution Improves

  • It keeps the best deterministic Task 2 completion metrics so far.
  • It keeps the strong Task 1 Top-k and LOFO behavior from Solution 2.
  • It removes the direct Task 3 dependency on validate_sequence() during prediction.
  • It makes anomaly attribution easier to explain in a demo.

What This Still Is Not

This is not a neural anomaly detector. The conformance checker is a transparent symbolic layer. It is useful and explainable, but it does not prove that a learned model rediscovered the process rules.

The next real research step would be to train a sequence model, use per-step surprisal to localize anomalies, and then compare that learned detector against this semantic conformance layer.
