How to Submit Solution 14

This page gives manual submission steps for the generated-data ensemble solution. It assumes you are in the repository root on branch dev/bati.

1. Regenerate the outputs

python -B solutions/solution_14_synthetic_ml_generator_ensemble/solution.py

This trains the generated-data fallback model in memory and writes the official-shaped CSVs.

2. Validate the exact CSV contract

python -B - <<'PY'
from pathlib import Path
import csv

root = Path("solutions/solution_14_synthetic_ml_generator_ensemble/outputs/official_submission")
expected = {
    "nextstep.csv": (["EXAMPLE_ID", "RANK_1", "RANK_2", "RANK_3", "RANK_4", "RANK_5"], 600),
    "completion.csv": (["EXAMPLE_ID", "PREDICTED_SEQUENCE"], 600),
    "anomaly.csv": (["EXAMPLE_ID", "IS_VALID", "SCORE", "PREDICTED_RULE"], 987),
}
for name, (header, rows_expected) in expected.items():
    with (root / name).open(newline="", encoding="utf-8") as f:
        reader = csv.reader(f)
        actual_header = next(reader)
        rows = sum(1 for _ in reader)
    print(name, actual_header == header, rows)
    assert actual_header == header
    assert rows == rows_expected
PY

3. Refresh the package folder

python -B solutions/prepare_submission_packages.py

4. Submit these packaged result files

  • solutions/solution_14_synthetic_ml_generator_ensemble/submission_package/extras/results/nextstep.csv
  • solutions/solution_14_synthetic_ml_generator_ensemble/submission_package/extras/results/completion.csv
  • solutions/solution_14_synthetic_ml_generator_ensemble/submission_package/extras/results/anomaly.csv

5. What to say in the report

Explain that the first stage uses exact prefix matches from validator-valid full routes in the participant input. The second stage is a large generated-data statistical fallback trained on 75,000 generated routes plus public routes.

6. Do not change the CSV headers

The official scorer is exact about column names. Keep the column order and names exactly as generated.
