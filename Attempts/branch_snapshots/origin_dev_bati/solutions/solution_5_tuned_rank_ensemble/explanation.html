Solution 5: Tuned Rank Ensemble

A standalone explanation of the retrieval plus multi-n-gram ranking attempt.

Read This First

This report is standalone. The industrial track gives process routes for semiconductor products. We must predict the next step, complete the remaining suffix, and detect rule violations. Solution 5 focuses mainly on Task 1: the quality of the ranked next-step list.

It does not require knowing any previous solution. The entire idea is: combine a retrieval model with several simple statistical models, then rank next-step candidates by their combined score.

What Is A Rank Ensemble?

A rank ensemble means multiple predictors vote on the same ranked list. Here, the predictors are:

  • A retrieval model that finds similar historical contexts.
  • A 3-gram model that looks at the previous two steps.
  • A 4-gram model that looks at the previous three steps.
  • A 5-gram model that looks at the previous four steps.

Each predictor gives candidate next steps. The solution turns those candidate rankings into scores and sorts by total score.

N-Grams Explained Without Jargon

An n-gram model is a count table. It looks at recent history and asks what usually came next in the training data.

ModelRecent context usedExample question
3-gramPrevious 2 steps"After these two steps, what usually follows?"
4-gramPrevious 3 steps"After this three-step pattern, what usually follows?"
5-gramPrevious 4 steps"After this longer four-step pattern, what usually follows?"

Shorter contexts are less specific but more robust. Longer contexts are more specific but can fail if the exact pattern was rare. Combining several orders tries to get both kinds of evidence.

How The Retrieval Part Works

The retrieval model indexes contexts near the expected 60% and 80% cut points in training sequences. When a new prefix arrives, it searches for similar recent contexts and lets those historical contexts vote for the next step.

Retrieval is useful because semiconductor routes are highly structured. If two lots are both near a via-etch block or passivation block, their next steps are likely to be similar.

How The Scores Are Combined

Retrieval candidates receive scores based on match quality and retrieval rank. N-gram candidates receive reciprocal-rank scores: rank 1 gets more weight than rank 2, rank 2 gets more than rank 3, and so on. 

for model in self.ngrams.values():
    for rank, step in enumerate(model.next_step_ranking(prefix, k=20)):
        scores[step] += NGRAM_WEIGHT / (rank + 1) / len(self.ngrams)

The fixed configuration in this solution is:

  • NGRAM_ORDERS = (3, 4, 5)
  • RETRIEVAL_WEIGHT = 1.0
  • RETRIEVAL_RANK_DECAY = 0.2
  • NGRAM_WEIGHT = 20.0

Limitations

This solution is a useful ablation, but it is not the strongest current result. It nearly matches the eval-aware retrieval approach on seed 42, but the separate synthetic-augmentation approach performs better on the main in-distribution metrics by adding generated valid routes to the training evidence.

It also does not solve exact-label randomness. If the generator randomly chooses between equivalent step labels, a ranker can know the right operation and still miss exact Top-1.
