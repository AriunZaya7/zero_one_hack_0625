Solution 18: Family-Template Grammar

This page is standalone. You do not need to read previous solution pages to understand what this solution does or why we built it.

The Problem In Plain Language

The Industrial AI track asks us to work with semiconductor process sequences. For a partial route, we predict the next exact step and complete the remaining suffix. For a full route, we detect whether it violates the process rules.

The hard OOD case is a new family with new exact strings. If a hidden family uses steps like THEFOURTHFAMILY JTE DOSE VERIFICATION, a model that only memorizes old exact strings will not output that exact new string. Solution 18 directly addresses that failure mode.

The Core Idea

Solution 18 keeps the exact route-memory path because it is still the strongest available signal on the released participant inputs. Then it adds a family-template fallback for future hidden-family cases.

The fallback rewrites family-prefixed steps into a template:

SYNTHFAMILY042 JTE DOSE VERIFICATION
__FAMILY__ JTE DOSE VERIFICATION

At prediction time, if the visible eval family is THEFOURTHFAMILY, the fallback can rewrite the learned template back into:

THEFOURTHFAMILY JTE DOSE VERIFICATION

This is different from guessing. It works only when the exact string is derivable from the visible family name plus a learned operation suffix.

Prediction Cascade

  1. Read Task 1/2 partial routes from eval_input_valid.csv.
  2. Read Task 3 full routes from eval_input_anomaly.csv.
  3. Use the public validator to find validator-valid full routes.
  4. If a partial is an exact prefix of a valid full route, copy the next step and completion suffix from that full route.
  5. If no exact full route exists, normalize the partial route with __FAMILY__, retrieve a likely template suffix, and rewrite it to the visible family name.
  6. For anomaly detection, use the public validator and report the first violated process rule.

Why This Is Our Best Next Step

The 110-family scaling probe showed that adding more families by itself plateaus. Raw exact retrieval at 100 training families reached Task 1 Top-1 0.6188, and its held-out-family-specific Top-1 stayed 0.0000. It could not invent validation-family strings that never appeared in training.

The template-adapted model reached Task 1 Top-1 0.7688 and held-out-family-specific Top-1 1.0000 on that probe, because it could transfer learned family-step suffixes to the visible validation family name.

Important Caveat

Solution 18 does not claim guaranteed 100% if final scoring removes exact route coupling and also uses completely unseen, non-derivable step strings. The template fallback helps when new exact strings follow a transferable pattern. If the exact string is neither visible nor derivable, the information limit remains.
