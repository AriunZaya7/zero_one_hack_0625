How To Submit Solution 17: Conformal Route Guard

Use these manual steps from the repository root on branch dev/bati.

1. Check The Branch

git branch --show-current
git status --short --branch

The branch should be dev/bati. The status should not show unrelated local changes before you regenerate outputs.

2. Regenerate This Solution

python -B solutions/solution_17_conformal_route_guard/solution.py

This writes the three upload-facing CSVs here:

  • solutions/solution_17_conformal_route_guard/outputs/official_submission/nextstep.csv
  • solutions/solution_17_conformal_route_guard/outputs/official_submission/completion.csv
  • solutions/solution_17_conformal_route_guard/outputs/official_submission/anomaly.csv

It also writes valid_guard_audit.csv and calibration_report.csv. These two audit files are for our development evidence and demo story. They are not replacement official output files.

3. Regenerate All Official Submission Copies

python -B solutions/generate_official_submissions.py
python -B solutions/prepare_submission_packages.py

The package generator copies the official-input CSVs into:

  • solutions/solution_17_conformal_route_guard/submission_package/extras/results/nextstep.csv
  • solutions/solution_17_conformal_route_guard/submission_package/extras/results/completion.csv
  • solutions/solution_17_conformal_route_guard/submission_package/extras/results/anomaly.csv

4. Check Exact CSV Headers And Row Counts

python - <<'PY'
import csv
from pathlib import Path
root = Path("solutions/solution_17_conformal_route_guard/submission_package/extras/results")
expected = {
    "nextstep.csv": (["EXAMPLE_ID","RANK_1","RANK_2","RANK_3","RANK_4","RANK_5"], 600),
    "completion.csv": (["EXAMPLE_ID","PREDICTED_SEQUENCE"], 600),
    "anomaly.csv": (["EXAMPLE_ID","IS_VALID","SCORE","PREDICTED_RULE"], 987),
}
for name, (header, rows) in expected.items():
    with (root / name).open(newline="", encoding="utf-8") as f:
        reader = csv.reader(f)
        actual_header = next(reader)
        actual_rows = sum(1 for _ in reader)
    assert actual_header == header, (name, actual_header)
    assert actual_rows == rows, (name, actual_rows)
print("Solution 17 CSVs are submission-shaped.")
PY

5. Check The Guard Audit

Open these if someone asks what happens if exact route matching stops covering every partial row:

  • solutions/solution_17_conformal_route_guard/outputs/valid_guard_audit.csv
  • solutions/solution_17_conformal_route_guard/outputs/calibration_report.csv

Important: the guard audit is not the official scoring file. It is an extra risk-control artifact. The official upload files remain nextstep.csv, completion.csv, and anomaly.csv.

6. What To Upload Or Reference

For a manual Tally/repo submission, reference the repository branch and use this package folder as the concrete artifact:

solutions/solution_17_conformal_route_guard/submission_package/

The exact CSV files are under submission_package/extras/results/. The report and demo notes are in the package root and extras/demo/.
