How to Submit Solution 21

This guide is written as manual steps. It assumes you are in the shared repository root.

1. Confirm the repository and dependencies

cd /Users/batikanorpava/Documents/other_development/2026-may30-vienna/zero_one_hack_0625
python - <<'PY'
import xgboost, catboost
print("xgboost", xgboost.__version__)
print("catboost", catboost.__version__)
PY

XGBoost and CatBoost should import successfully.

2. Regenerate this solution

python -B solutions/solution_21_template_boosted_bridge/solution.py

This writes the required three CSV files and the XGBoost raw-vs-template diagnostic outputs. It may take a little longer than the deterministic retrieval solutions because it trains multiple small XGBoost models.

3. Check the required CSV files

python - <<'PY'
from pathlib import Path
import csv
base = Path("solutions/solution_21_template_boosted_bridge/outputs/official_submission")
expected = {
    "nextstep.csv": ["EXAMPLE_ID", "RANK_1", "RANK_2", "RANK_3", "RANK_4", "RANK_5"],
    "completion.csv": ["EXAMPLE_ID", "PREDICTED_SEQUENCE"],
    "anomaly.csv": ["EXAMPLE_ID", "IS_VALID", "SCORE", "PREDICTED_RULE"],
}
for name, header in expected.items():
    path = base / name
    with path.open(newline="", encoding="utf-8") as f:
        reader = csv.reader(f)
        actual = next(reader)
        rows = sum(1 for _ in reader)
    print(name, actual == header, rows)
PY

Expected row counts are 600 for nextstep.csv, 600 for completion.csv, and 987 for anomaly.csv.

4. Package the solution

python -B solutions/prepare_submission_packages.py

The package for this solution will be created under solutions/solution_21_template_boosted_bridge/submission_package/.

5. Upload the official CSVs

  1. Open the hackathon submission page.
  2. Choose the Industrial AI / Infineon track submission form.
  3. Upload outputs/official_submission/nextstep.csv for Task 1.
  4. Upload outputs/official_submission/completion.csv for Task 2.
  5. Upload outputs/official_submission/anomaly.csv for Task 3.
  6. If the form accepts supporting material, attach or reference the generated submission package and explanation.html.
  7. Before final submit, verify the column headers exactly match the track specification.
