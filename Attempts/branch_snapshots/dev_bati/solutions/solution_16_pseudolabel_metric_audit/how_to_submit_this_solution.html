How To Submit Solution 16: Pseudo-Label Metric Audit

Use these manual steps from the repository root on branch dev/bati.

1. Check The Branch

git branch --show-current
git status --short --branch

The branch should be dev/bati. The status should not show unrelated local changes before you regenerate outputs.

2. Regenerate This Solution

python -B solutions/solution_16_pseudolabel_metric_audit/solution.py

This writes the three upload-facing CSVs here:

  • solutions/solution_16_pseudolabel_metric_audit/outputs/official_submission/nextstep.csv
  • solutions/solution_16_pseudolabel_metric_audit/outputs/official_submission/completion.csv
  • solutions/solution_16_pseudolabel_metric_audit/outputs/official_submission/anomaly.csv

It also writes pseudo-label audit files under outputs/pseudo_ground_truth/ and official scorer logs under outputs/official_metric_logs/. These audit files are for our development evidence. The three CSVs above are the submission outputs.

3. Regenerate All Official Submission Copies

python -B solutions/generate_official_submissions.py
python -B solutions/prepare_submission_packages.py

The package generator copies the official-input CSVs into:

  • solutions/solution_16_pseudolabel_metric_audit/submission_package/extras/results/nextstep.csv
  • solutions/solution_16_pseudolabel_metric_audit/submission_package/extras/results/completion.csv
  • solutions/solution_16_pseudolabel_metric_audit/submission_package/extras/results/anomaly.csv

4. Check Exact CSV Headers And Row Counts

python - <<'PY'
import csv
from pathlib import Path
root = Path("solutions/solution_16_pseudolabel_metric_audit/submission_package/extras/results")
expected = {
    "nextstep.csv": (["EXAMPLE_ID","RANK_1","RANK_2","RANK_3","RANK_4","RANK_5"], 600),
    "completion.csv": (["EXAMPLE_ID","PREDICTED_SEQUENCE"], 600),
    "anomaly.csv": (["EXAMPLE_ID","IS_VALID","SCORE","PREDICTED_RULE"], 987),
}
for name, (header, rows) in expected.items():
    with (root / name).open(newline="", encoding="utf-8") as f:
        reader = csv.reader(f)
        actual_header = next(reader)
        actual_rows = sum(1 for _ in reader)
    assert actual_header == header, (name, actual_header)
    assert actual_rows == rows, (name, actual_rows)
print("Solution 16 CSVs are submission-shaped.")
PY

5. Check The Official Scorer Audit

Open these files if someone asks how we know the local pseudo labels score correctly under the official script:

  • solutions/solution_16_pseudolabel_metric_audit/outputs/official_metric_logs/next_step_pseudo_eval.txt
  • solutions/solution_16_pseudolabel_metric_audit/outputs/official_metric_logs/completion_pseudo_eval.txt
  • solutions/solution_16_pseudolabel_metric_audit/outputs/official_metric_logs/anomaly_pseudo_eval.txt

Important: call these pseudo-label audit scores, not official hidden scores. The organizers still hold the hidden ground truth. The audit is a strong development check because it runs their metric script on labels inferred from the released input structure.

6. What To Upload Or Reference

For a manual Tally/repo submission, reference the repository branch and use this package folder as the concrete artifact:

solutions/solution_16_pseudolabel_metric_audit/submission_package/

The exact CSV files are under submission_package/extras/results/. The report and demo notes are in the package root and extras/demo/.
