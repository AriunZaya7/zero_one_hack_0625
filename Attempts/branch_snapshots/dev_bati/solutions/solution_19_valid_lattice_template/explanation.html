Solution 19: Valid-Lattice Template

This page is standalone. It explains the solution without assuming you have read any previous solution page.

The Problem In Plain Language

The Industrial AI task asks us to predict exact semiconductor process step strings. OOD means the organizers may test us on a new product family. A new family is hard because it may use new exact strings, and exact-string scoring gives no credit for a nearly correct spelling or synonym.

Solution 18 handled derivable new strings with a family template such as __FAMILY__ JTE DOSE VERIFICATION. Solution 19 adds another source of evidence: longer partial routes that are already present in the evaluation input.

What A Valid-Partial Lattice Means

A lattice here is just a small graph of partial routes. If one partial route is a prefix of another partial route, the longer route gives us more known steps.

60% partial:
RECEIVE WAFER LOT | ... | DEVELOP PHOTORESIST

80% partial from the same route:
RECEIVE WAFER LOT | ... | DEVELOP PHOTORESIST | THEFOURTHFAMILY JTE DOSE VERIFICATION | STRIP RESIST | ...

For the 60% row, the exact next step is visible inside the 80% row: THEFOURTHFAMILY JTE DOSE VERIFICATION. We do not need to guess the hidden-family generator seed. We only use input rows that the submitted system receives.

Prediction Cascade

  1. Read Task 1/2 partial routes from eval_input_valid.csv.
  2. Read Task 3 full routes from eval_input_anomaly.csv.
  3. Use the validator to find valid full routes. If a partial is a prefix of a valid full route, copy the exact answer from that route.
  4. If no full route exists, search the valid-input file for a longer partial that starts with the current partial.
  5. If a longer partial exists, use it to predict the next step and a known completion bridge.
  6. If no longer partial exists, fall back to the normalized __FAMILY__ template grammar.
  7. For anomaly detection, use the public validator and report the first violated rule.

What The Curves Told Us

The previous 110-family curve showed that simply adding more families is not enough. Raw exact retrieval stayed around 0.6188 Task 1 Top-1 at 100 training families because it cannot invent validation-family exact strings. Template retrieval improved to 0.7688, because it can rewrite __FAMILY__ templates to a visible family name.

After adding the valid-partial lattice to the same curve, the 100-family OOD probe reached 0.8938 Task 1 Top-1 and 0.1066 Task 2 edit distance. That is the strongest current evidence for the next OOD layer.

Important Caveat

The lattice is a conditional advantage. It helps only when multiple partials from the same hidden route are visible. If final hidden OOD scoring has no full routes and no longer partials, Solution 19 falls back to the family-template grammar from Solution 18. The audit file makes this visible row by row.
