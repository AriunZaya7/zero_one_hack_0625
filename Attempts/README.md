# Attempts Archive

This folder intentionally contains material that is not part of the clean
submission root.

## Branch Snapshots

`branch_snapshots/` contains archive snapshots of:

- `main`
- `dev/bati`
- `SECONDCRISTI`
- `origin/main`
- `origin/angie`
- `origin/cristi/modeling`
- `origin/dev/bati`
- `origin/morgan`
- `upstream/main`

Each snapshot has `.source_ref` and `.source_commit` files.

## Local Workspace Experiments

`local_workspace_experiments/` contains old reports, previous submission
bundles, broad solution experiments, old baselines, smoke outputs, and build
scratch files that were useful for choosing the final solution but should not
crowd the actual submission package.
